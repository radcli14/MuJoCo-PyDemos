# MuJoCo-PyDemos

A series of demonstrations of the [MuJoCo](https://mujoco.org) physics engine using Python code.

See [SETUP.md](SETUP.md) for environment and installation instructions.

## Demos

- [**Rattleback (Celtic Stone)**](rattleback/) — an ellipsoidal stone whose tilted
  inertia axes make it spontaneously reverse its spin direction.
- [**Double Pendulum**](double_pendulum/) — two plexiglass links on frictionless hinges
  swinging under lunar gravity; chaotic motion emerges within seconds from a near-inverted start.
- [**T-Handle**](t_handle/) — a free-floating steel T-handle in zero gravity demonstrating
  the intermediate axis theorem: periodic 180° flips with angular momentum and energy conserved.
