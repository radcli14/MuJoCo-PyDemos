This site is a static website hosted on [GitHub Pages](https://pages.github.com).
It has no user accounts, no comment system, no advertising, and no analytics.

## What is collected and by whom

### GitHub Pages (hosting)

The site is served by GitHub Pages.
GitHub may log standard server request data — IP address, browser type, referring URL, and timestamp — as part of normal web server operation.
This data is governed by [GitHub's Privacy Statement](https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement).

### jsDelivr CDN (Bootstrap and MathJax)

Bootstrap (layout framework) and MathJax (math rendering) are loaded from the [jsDelivr](https://www.jsdelivr.com) CDN.
jsDelivr receives the visitor's IP address for each request.
Their data practices are covered by the [jsDelivr Privacy Policy](https://www.jsdelivr.com/privacy-policy-jsdelivr-net).

### YouTube (embedded videos)

Demo pages with video embeds use `youtube-nocookie.com`, YouTube's privacy-enhanced embed domain, which defers cookie-setting until the user clicks play.
YouTube thumbnail images load from `img.youtube.com` automatically when a page with a video card is rendered, which sends the visitor's IP to Google.
Google's data practices are covered by the [Google Privacy Policy](https://policies.google.com/privacy).

### Fonts

Fonts (Inter and JetBrains Mono) are self-hosted and served directly from this site.
No requests are made to `fonts.googleapis.com` or `fonts.gstatic.com`.

## Cookies

This site does not set any cookies.
YouTube may set cookies if you interact with an embedded video player.
